À propos

Je code avant tout pour aider les autres : rendre accessible ce qui demande d'habitude une dizaine de commandes ou un après-midi de documentation.

Mon terrain de jeu, c'est Linux, l'open source et l'auto-hébergement. Je fais tourner mes propres serveurs, je publie mes outils sous licence libre, et je préfère comprendre comment une chose marche plutôt que d'importer une solution toute faite.

Côté terrain, je suis technicien de maintenance industrielle : automates, électricité, équipements. Ça se retrouve dans mes projets, entre logiciel et matériel.

Projets

Vigie

Gérer un serveur Linux depuis une seule fenêtre : surveiller la machine, créer des utilisateurs, suivre les processus, activer ou couper les services systemd. Le tout dans une interface terminal, utilisable en SSH, sans retenir une dizaine de commandes.

  • Interface plein écran, souris et shell bash intégré
  • Publié sur pub.dev, distribué par mon propre dépôt APT signé
  • Open source, licence MIT · écrit en Dart
