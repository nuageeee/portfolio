# nuage — portfolio

Mon portfolio de développeur : un ciel qui passe du lever au coucher de soleil,
des nuages, et mes projets Linux / open source.

En ligne : https://elnuageee.fr

## Développer

```bash
npm install
npm run dev
```

## Construire

```bash
npm run build   # résultat dans dist/
```

## Déployer

Le `Dockerfile` construit le site avec Node puis le sert avec Nginx (port 80).
Déployé sur mon VPS avec Dokploy.

## Stack

HTML, CSS et JavaScript sans framework, outillé avec Vite.
Polices auto-hébergées : Fraunces et Inter (licence SIL Open Font).
